โมเดลทำนายทิศทางราคา IREN ดีกว่าการเดาแบบง่ายหรือไม่

ความต่างของ Brier score เทียบการเดาแบบง่าย

จุดคือค่าเฉลี่ย เส้นคือช่วงความเชื่อมั่น 95% ถ้าทั้งเส้นอยู่ซ้ายของ 0 แปลว่าโมเดลทายความน่าจะเป็นได้ดีกว่าอย่างมีนัยสำคัญ แต่ละแถวใช้สเกลของตัวเอง เพราะช่วง "ถึงปิดตลาด" กว้างกว่าช่วงอื่นมาก

ทั้งช่วงต่ำกว่า 0 (Brier ดีกว่า) ช่วงคร่อม 0 (แยกไม่ออกจากการเดา)

อ่านผลอย่างไร

Baseline คืออะไร

การเดาแบบง่าย ใช้สัดส่วนที่ราคาเคยขึ้นในช่วงข้อมูลที่ใช้ฝึก แล้วทายค่านั้นทุกครั้ง โมเดลที่ดีต้องชนะวิธีนี้ให้ได้

Brier score

วัดความผิดพลาดของความน่าจะเป็น ยิ่งต่ำยิ่งดี 0.25 คือการทาย 50/50 ตลอด ความต่างที่เห็นอยู่ระดับ 0.001 ซึ่งเล็กมาก

เกณฑ์ EDGE

ต้องมีวันทดสอบอย่างน้อย 20 วัน Brier ต้องดีกว่า baseline ทั้งช่วงความเชื่อมั่น 95% และความแม่นยำต้องสูงกว่า baseline ครบทั้ง 3 ข้อ

สัญญาณมั่นใจ

สัดส่วนครั้งที่โมเดลให้ความน่าจะเป็น ≥ 0.55 หรือ ≤ 0.45 และความแม่นยำเฉพาะครั้งเหล่านั้น จำนวนครั้งน้อย จึงยังเชื่อถือไม่ได้มาก

ใช้เพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน ผลในอดีตไม่รับประกันอนาคต ยังไม่ได้หักค่าธรรมเนียมและ slippage
